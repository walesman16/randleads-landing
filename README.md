Modern landing page for RandLeadsAI, showcasing AI-powered lead generation solutions.

- Responsive design
- Modern UI/UX
- Integrated booking system
- Payment processing
- Mobile-friendly layout

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Custom animations and transitions

2. Open `index.html` in your browser
3. Make changes as needed
